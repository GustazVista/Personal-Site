# Personal Site

Welcome to the project I have built, which is a personal portfolio website. 

# About the website

The website is one-page, so the links in the navigation bar lead to the corresponding place on the front page. 

# How this works

There are about link, Hobbies/Interests link and Contact links in the navbar, so they help you to move around the site.
